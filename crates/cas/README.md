# nrz-cas · `guide:cas:overview`

`nrz-cas` constructs exact mathematical graphs, checks conditional identity witnesses, searches bounded equality routes and produces scalar derivatives, Jacobians and rational square-free layers with explicit sorts, contexts, binder scopes, resource budgets and original source occurrences. Native cases add complete source inspection, reached-region elaboration, local agreement, merge, ownership and bounded common refinement to semantic headers, exact region judgments, qualified local contexts and typed portable replay, following `docs/design/cas-piecewise-design.md`. It has no consumer yet and introduces no physical units or numerical evaluator.

The root exports `Cas`, handles/references, `Rational` and structured faults. Construction lives in `syntax`, domains/headers/contexts in `domain`, occurrence coverage in `source`, tasks/results/search in `request`, judgments/witnesses in `proof`, and accounting in `limits`. A `Request` pairs each occurrence root with its matching receipt in `CoveredInput` and retains explicit witness premises. The retained `Draft::Request` boxes its `Limits` payload to bound draft size; the executable `Request` retains value-owned limits.

**Definition (Scoped region capability)** · `def:cas:scoped-regions`

Headers separate immutable declarations from assumptions. `Core` is space-free; `Extend` adds fresh declarations referring only to earlier spaces and cannot shadow existing keys. Regions use exact ambient, empty, guard-true, guard-false, meet, union and difference constructors. The checker decides rational affine comparisons and integer cells, preserving singleton endpoints and strict definedness; an undefined guard is neither true nor false. Real distribution spaces currently require a nonempty connected open interval and the `CompactSmooth` test family.

A local context records its parent, exact admissible meet and qualified frame slots. Hypothesis use names its introducing context and slot; siblings cannot borrow that identity. Closure removes only used local assumptions, using supplied parent evidence or retaining a guarded residual on the child region. Restriction requires an explicit checked subset premise. Predicate facts are checked on exact nonempty regions; empty-region facts hold vacuously without evaluating their predicate. An empty requested function domain refuses.

`source::ordered_cases` and `source::case_literal` build complete original forms and distinct occurrences atomically. `describe_syntax` exposes constructor payloads and typed dependency roles for expressions, conditions, regions, arms, boundaries, spaces and source forms. Original walks include every selector and branch, including inactive partial expressions. `ElaborateCases` requires an original receipt and checks the ordered reached-region recurrence; an undefined reached guard never falls through.

The five case schemas reconstruct exact domains, local selection, overlap compatibility and complete congruence. Rational polynomial identities are checked on real open cells and values are evaluated exactly at rational singletons. `Merge` records domain proofs, a cover, local equalities and closure, preserving both definedness directions. `Boundary` with `Ownership` records function-specific `Present(value)` or certified `Absent`; missing evidence remains `PendingPremise`. `Coverage` proves definedness on the requested region, distinguishes `UnknownTotality` from a proved hole, and preserves unsupported predicates as blockers. General integer-cell agreement beyond polynomial identity or exact singleton evaluation remains pending.

Native `Simplify` schedules common-refinement pairs lazily on the cost and progress queues. Empty pairs consume the shared refinement allowance, nested jobs share the same ledger, positive growth is charged, and each complete result retains a checked cover. Boundary calculus adds finite selector partitions, polynomial side jets, classical cell and point derivatives, witnessed nonexistence, and transparent named definitions. Distribution calculus adds checked regular embeddings, finite jump derivatives, delta actions and polynomial smooth multipliers in an exact declared space.

**Definition (Certified boundary calculus)** · `def:cas:boundary-calculus`

`Task::Boundary` names its real coordinate and point. `Jets { order }` requests traces from zero through that order; `Jump { order }` requests the right-minus-left trace difference; `Derivative { order }` names a positive iterated classical derivative order. Complete finite partition evidence reconstructs every reachable case selector and requested-domain endpoint. Geometry alone supplies no analytic regularity: each jet additionally requires total local equality to a rational polynomial and an independently checked incident open neighborhood.

`jet.polynomial` checks factorial-weighted shifted coefficients, with separate closed partition, trace-projection and jump-introduction modes. The derived `jet.jump` recipe records both projections and exact subtraction. `diff.case-interior` transports an existing scalar derivative through local equality on an open cell; its assembly mode checks all cells of the claimed derivative region. `diff.case-boundary` first compares both function traces with actual function-specific ownership, then compares slopes. Missing ownership or a side stays pending. Thus equal branch slopes do not rescue J's jump.

`Cas::named_case` builds `NamedCase { name, coordinate, parameter }` with a retained canonical case operand. The checked case machinery unfolds abs, sign, ramp and a step whose rational parameter is its value at zero. Ordinary coordinate substitution must use an expanded definition; `rename_axes` transports the coordinate and definition together. Names grant no primitive shortcut.

`SearchResult::payload` boxes typed calculus results. A sealed `DerivativeMap` retains the complete selector partition, all replayed facts, pending cells, a separate derivative theorem on the union of successful cells, and an optional complete requested-domain derivative theorem. Higher orders consume the actual previous derivative, including owned point values. Abs and ramp have side derivatives −1/+1 and 0/1 with witnessed nonexistence at zero. J has owned value 1, traces 0/1 and slopes 0/0, so its derivative fails there. Q has first derivative zero at zero and second-derivative traces 2/4, proving second-derivative nonexistence.

**Definition (Checked distribution calculus)** · `def:cas:distribution-calculus`

`EmbedRegular { space }` certifies finite polynomial cells before constructing a regular distribution. `DistributionStatement` groups regularity, embedding, equality, derivative, pairing and supported-action judgments under `Statement::Distribution`. Every judgment retains its exact real coordinate, open interval and test family, including scalar-valued pairing results. Regular representatives may differ at certified finite points; their pointwise ownership remains distinct.

The nine version-one schemas are `dist.regular`, `dist.ae`, `dist.linear`, `dist.derivative`, `dist.delta-pair`, `dist.smooth`, `dist.delta-multiply`, `dist.support-action` and `dist.jump`. The jump checker independently compares polynomial derivatives and right-minus-left traces on the complete partition. Higher derivatives repeat the first-order rule and increment existing delta orders. Ordinary declared tests produce symbolic derivative evaluations; `PairNearSupport` instead requires a checked finite delta support and a polynomial germ on an explicit neighborhood. It evaluates `PairNearSupport(δ₂, x² + 3) = 7` and `PairNearSupport(δ′₂, x² + 3) = −4` without classifying a polynomial as a compactly supported test.

The derived integration-by-parts, delta-primitive and classical-bridge recipes retain primitive expansions and add no registry keys. Named and expanded routes enter both queues before completed-result dominance. Native equality shortcuts retain replayable expansions and the older frozen cost manifest; strict improvement is checked in the complete typed theorem class without scalar projection. Partition reuse applies during generation and independent replay.

`ApplyAt` refuses distribution point values; `Product` refuses delta-square and a multiplier proved discontinuous at the delta support. The corresponding public reasons are `DistributionPointValue`, `DistributionProductUndefined` and `TestSpaceMismatch`. Unsupported smoothness remains `PendingPremise`. The independent `delta_order`, `test_nodes` and cumulative `pairing_steps` limits cover these operations.

**Definition (Construction capability)** · `def:cas:construction`

`Cas::admit` validates flat child-before-parent drafts and publishes them atomically. Handles carry a private store identity; public logical identifiers never authorize a lookup in another store. Graph-owned expression records share exact syntax, while each original operand use keeps a distinct occurrence, optional checked UTF-8 byte span and ordered child links. Sources with conflicting bytes under one key are refused. Failed admission preserves the published graph and all next identifiers.

`Operator` represents scalar arithmetic, declarations and calls, derivatives, integral/sum/series/limit bodies, predicates and solution sets, matrices and comprehensions, matrix operations, spectral requests and selected algebraic roots. Admission checks arity, sort, matrix shape and explicit de Bruijn frames. `ExpressionDraft::space` carries an optional exact typed link: ordinary pointwise scalar syntax requires absence, scalar-valued distribution actions retain their space, declared test/distribution leaves must match their declaration, and nonleaf space-dependent syntax requires an explicit matching space. Portable records and typed transformations retain that dependency. Representation supplies no evaluation, identity or proof of a predicate. Context keys sort declarations and named hypotheses, flatten conjunctions and reject recognized literal falsehoods or an atom paired with its explicit negation; unrecognized consistency remains unknown.

`Rational` owns canonical sign/magnitude, positive-denominator and reduction invariants over `num-bigint` 0.4 with default features disabled. Integers, fractions, decimals and decimal scientific notation parse exactly. Arithmetic cross-cancels before multiplication and uses continued fractions for comparison. The default component/intermediate limits are 4,096/8,192 bits; `(4/5)^78` fits with numerator/denominator sizes of 157/182 bits. Every big-integer operation prepays a conservative size-dependent work charge; a smaller bit budget returns `Exhausted` with `ArithmeticRange`. `petgraph` 0.8 supplies append-only graph storage. The gate-resolved lock pins `num-bigint` 0.4.8 and `petgraph` 0.8.3, including their exact transitive dependencies. This capability adds no dependency and preserves those lock bytes.

**Rule (Occurrence coverage before requests)** · `rule:cas:coverage`

`walk_original` visits every original operand in postorder, including operands beneath zero multiplication and cancellation candidates, with explicit binder-entry events. It returns a sealed `TraversalReceipt` only when the entire walk succeeds. A `WalkFailure` retains bounded partial events and the fault, with no receipt. A receipt proves coverage, not physical validity or mathematical definedness. A client must inspect the events and perform its own checks before submitting a request. `substitute` performs simultaneous capture-safe free substitution through the complete typed dependency graph; `instantiate_bound` replaces one explicit frame. Both return typed syntax, which must be materialized and walked again for a fresh receipt. `rename_axes` requires an `AxisMap` with exact coordinate, header and space correspondences; ordinary substitution cannot change a declared space or silently perform a coordinate pullback. `materialize_derived` produces fresh occurrences carrying provenance and no invented source spans, which `walk_derived` covers separately.

**Definition (Closed proof kernel)** · `def:cas:proof-kernel`

`Cas::check_proof(context, steps, budget)` checks a supplied child-before-parent proof DAG and returns a sealed `VerifiedWitness`. Its final `Judgment` names the full context, layer, optional space, typed statement and canonical guarded residuals. The closed `Primitive` vocabulary has 52 version-one schemas: equality structure and ordered congruence, scalar field laws, exact rational arithmetic, finite polynomial/rational coefficient identities, elementary scalar derivative rules, equality transport, simultaneous substitution, ordered Jacobian assembly, certified square-free layers, `ctx.hypothesis`, `ctx.weaken`, `ctx.close`, `region.decide`, `region.construct`, `case.ordered`, `case.domain`, `case.select`, `case.congruence`, `case.eliminate`, `jet.polynomial`, `diff.case-interior`, `diff.case-boundary` and the nine distribution schemas above. The case certificates retain the complete reconstructed region and association inventory and exact cell evidence. `PRIMITIVES` exposes keys, semantic versions, conclusion/premise/certificate metadata and positive weights under the current `logical` policy version 5. Callers cannot register a trusted callback or label an arbitrary equation primitive. The schema matchers reconstruct conclusions and check each ordered premise; derivative relations cannot be reversed or composed as equality.

The graph owns checked Application and Proof records, their context/endpoints, ordered premise links and typed domain conditions. Scoped application edges reconstruct each statement's region, boundary, side, function and ordered value roles; unordered cover members use canonical local identity order. Admission is atomic, including failed proof imports and substitutions. A proof references only earlier proofs; unreachable or duplicate canonical proof records are rejected. `register_derived` replays a sealed witness in an independent empty store, compares its exact expected claim, and admits only a positive strict cost improvement over known routes for the same context/endpoints/relation/residual set. A shortcut retains its older proof dependency; it never replaces that evidence. The compiled registry stays closed and versioned. `register_derived_with_policy` replays an equality witness and requires strict improvement over the finite known equality routes under its complete pinned table; shortcuts registered under another policy cannot supply a stale improvement record.

**Rule (Visible domain evidence)** · `rule:cas:proof-domains`

The kernel derives requirements from both complete endpoints and every premise. Rational facts, exact named hypotheses, positivity implying nonzero, and nonzero products/integer powers discharge guards through bounded checks. Unknown requirements remain explicit `GuardedObligation` tuples naming home context, scope, layer, space, region and predicate; a refuted requirement blocks admission. The condition set acts as conjunction introduction, while conjunction hypotheses are projected with their original hypothesis key. Cancellation of x/x retains x nonzero; multiplication by zero retains the definedness of its other operand. Zero powers follow the strict nonzero-base convention, and the exponent-one derivative uses the child derivative directly. Simultaneous theorem substitution transports every requirement, including previously assumed ones, so an x nonzero hypothesis cannot justify substituting zero into x/x.

`is_discharged()` means no residual remains. `hypotheses()` still identifies every context assumption used, and `context_consistency()` remains `Unknown`. Open binder requirements retain their checked term scope; the scalar checker cannot turn one bound instance into a universal fact. No proof or witness supplies a physical validation receipt. Field identities follow the scalar field axioms; coefficient equality compares finite exact maps after reconstructing both endpoints, and rational equality retains original guards before cross multiplication. The mathematical arguments and derivative formulas are in `docs/design/cas-design.md`. Coefficient maps are temporary checked views of graph syntax, bounded by total degree, the union of variables across monomials, nonzero term count, measured scratch storage and exact arithmetic work.

**Definition (Portable mathematical witnesses)** · `def:cas:portable-witnesses`

`export_witness` writes only `NRZCAS02`: the used primitive manifest, canonical typed dependency records and complete conclusion. Headers, regions, spaces, expressions, arms, boundaries, source forms, predicates, contexts, guarded obligations, statements and applications have distinct record schemas. Kahn ordering chooses ready structural descriptors with already assigned child indices; unordered semantic sets use portable structural order. Runtime handles, graph serials, search costs and original receipts are absent. `NRZCAS01` is refused as `UnsupportedVersion`. There are no external consumers or stored artifacts requiring a compatibility reader.

`replay(bytes, expected_judgment, budget)` reconstructs all mathematical tables through ordinary admission, checks every primitive and condition again, compares the complete canonical re-encoding, and compares the caller's expected full context, statement, domain, layer, space and guarded residual set. Expected terms cannot be reinterpreted under a different semantic header. `inspect` performs the same checking while deliberately reporting what the bytes prove without an acceptance target. A different valid theorem is rejected by `replay`; a different valid proof of the intended theorem is permitted. Truncated/extended streams, forward references, unused records, unknown rule versions, nonminimal numbers, changed guards and mismatched claims refuse without publishing a decoded prefix. The separate replay allowance covers decoding, construction, checking, publication and expected-claim comparison before work occurs.

**Procedure (Bounded identity search)** · `alg:cas:identity-search`

`Equal` and `Simplify` share two ordered queues, positive cost/progress quotas and a resumable finite rule/position cursor. The default epoch takes four cost visits and one progress visit. Matching, copying, container comparisons, arithmetic and conditions consume monotone ledgers. Structural expansion, exact coefficient collection and monomial cancellation propose ordinary proof steps; the kernel reconstructs every admitted edge. Existing proofs and policy-compatible shortcuts are expanded to their older primitive dependencies before reuse. The difference-quotient fixture requires an explicit larger intermediate before collection reaches its target, retaining the increment's nonzero guard. `Expand` materializes the bounded polynomial coefficient expression and checks the resulting finite-jet edge.

Each label retains cost, peak unfolded size, cumulative positive expansion credits, proof depth, witness footprint and proof/domain support. Dominance requires all resource dimensions to improve without increasing support, and never crosses context or residual classes. Exact ties use canonical proof bytes. The best result stays within the initial residual class; a policy requiring discharge cannot hide an initial unknown guard. An equality target must be reached exactly before a successful result is returned. An incomplete frontier or refused candidate never proves that no other route exists. These are heuristic routes, with no global shortest-path claim.

**Definition (Pinned logical costs)** · `def:cas:cost-policies`

`run_with_policy` accepts a `SearchPolicy` containing a complete positive `CostPolicy` table and conditional-result permission. Every immutable table is stored in the graph with its key, version and full primitive manifest. Reusing an identity/version with different contents is invalid. Default weights use `logical` version 5 with all 52 active checkers; a changed table requires a new version; custom weights are at most 1,000,000. Logical transition cost and expanded primitive count are reported separately. `certify_frozen_cost` projects only checked equality applications in the exact context/residual class, pins its manifest and table, and settles every reachable endpoint by bounded positive-weight Dijkstra. Its sealed certificate states a shortest cost or finite-snapshot unreachability. New applications affect only a new manifest; exhaustion yields no certificate. Raw operands, source links and proof-dependency links are never cost edges.

**Procedure (Generated scalar calculus)** · `alg:cas:generated-calculus`

Differentiation uses an explicit postorder stack and memoizes by expression, context and ordered variable key. It proposes constant, variable, negation, sum, difference, product, quotient and fixed-integer-power formulas. Simplification requires checked rational identities and derivative transport. Composite denominators retain factored syntax when coefficient expansion would introduce additional unknown guards. Zero and negative powers retain nonzero conditions; exponent one avoids a new zero power. Unknown functions and other unimplemented grammar produce an unresolved blocker naming the pending logical expression. No whole Jacobian is emitted until all ordered partials check. Shared expressions reuse proof work while the requested row and variable order remain explicit.

The three-output pendulum fixture checks a three-by-eight Jacobian, the shared final two columns and exact nominal coefficients. Its simultaneous operating-point substitutions are also applied to original domain judgments with the equality-instantiation schema. Independent hand formulas give the nonzero cells pi², -(621/625)pi² and -(1242/625)pi². Neither those symbolic derivatives nor their substitutions infer a covariance model or physical validity.

A request uses distinct generation and checker work ledgers; every candidate check shares the same checker allowance. A best result additionally undergoes fresh-store canonical byte replay before return. Higher derivative levels replay the necessary proof roots, whose checked dependency closures also certify their retained subproofs. An unrelated nonexistence fact needs its own replayed root; all replay work shares the original request allowance. Each ledger memoizes successful exact region partitions by complete portable syntax, ordered roots, the optional boundary cut and active ceilings. Fresh receiving stores can reuse those decisions; every supplied certificate and asserted relation is still checked. The cache reserves staged payload, and key construction, lookup and copying remain metered. `SearchResult` reports both usages, its exact endpoint trace and full policy. Its optional `NRZRUN03` envelope separates costs, effective limits, counters and trace from the authoritative `NRZCAS02` witnesses, including every retained calculus component. If the optional response cannot fit, `response` is absent (NotExported) while the sealed in-store witness remains available for a later metered export. Minimal outcome metadata does not require optional output capacity.

**Procedure (Certified square-free layers)** · `alg:cas:square-free-layers`

`SquareFree` reconstructs a nonzero univariate polynomial over Q from scalar rational/real syntax, normalizes its leading coefficient, differentiates its coefficient vector and computes exact extended Euclidean certificates. Successive gcd/quotient layers follow the characteristic-zero recurrence in `docs/design/cas-design.md`. Each certificate states both divisibilities and a Bézout combination; the checker verifies those coefficient identities without running the producer's Euclidean loop. It also verifies the recurrence, monicity, nonconstant factors, strictly increasing positive multiplicities, each factor's derivative gcd, every pairwise gcd, the complete product identity and the exact displayed endpoint factors. Layers need not be irreducible; x²+1 remains a valid single layer over Q.

`SquareFreeCertificate`, `SquareFreeLayer` and `GcdCertificate` are untrusted public data with ascending-degree canonical rational vectors. `ApplicationDraft::certificate` uses `Certificate::SquareFree(Box<SquareFreeCertificate>)` only for `poly.square-free` version 1, with logical weight 8; other primitives reject that payload. `square_free_certificate` borrows checked evidence from the witness's graph application. The typed application contains the complete certificate; no earlier wire layout is retained. Every decoded coefficient/vector and retained certificate is bounded before copying or arithmetic. The producer publishes the factor expression and its replayed proof in one transaction.

A nonzero constant returns its scalar and no factors. Zero returns `Outcome::Unsupported` with `UnsupportedReason::ZeroPolynomialMultiplicity`; non-rational coefficients and expressions outside the univariate fragment have distinct reasons. Positive-characteristic and complex coefficient requests remain unsupported. Degree, coefficient/intermediate bits, arithmetic work, retained payload and witness bytes have explicit refusal paths. The degree-five fixture, a hand-authored Bézout certificate for x²+1, independent binomial examples, rational coefficients, endpoint/certificate tampering, canonical replay, byte determinism and exact witness-size boundary are acceptance tests. None of these claims infer roots or physical meaning.

**Caveat (Current executable scope)** · `cav:cas:construction-scope`

`Cas::run` executes bounded `Equal`, `Simplify`, `Expand`, `Differentiate`, `Jacobian`, `SquareFree`, `ElaborateCases`, `Select`, `Eliminate`, `Merge`, `Coverage`, `EmbedRegular`, `Pair`, polynomial `SmoothMultiply` and boundary ownership, jet, jump and explicitly ordered point derivative requests after validating complete matching occurrence receipts. `Proved` and `Conditional` contain independently checked results; the latter retains unresolved domain guards. Contradicted definedness and a proved empty requested function domain return `Refused` with `RefutedDomain` or `EmptyDomain`. Native unsupported premises return `PendingPremise`, and undecided coverage returns `UnknownTotality`; both carry any independently replayed partial facts. A checked point obstruction returns `Nonexistent`. Mixed whole-domain derivative results return `Partial` with a sealed `DerivativeMap`. Other represented tasks remain `Unresolved`, and excluded executable fields return `Unsupported`. Malformed inputs return `Invalid`; spent limits return `Exhausted` with only a previously replayed best result when available. `canonical_snapshot` is a deterministic graph diagnostic, not a mathematical witness or import format.

`Limits` names every storage, depth, bit, work and future algorithm ceiling; `LimitsOverride` resolves optional request changes. A `Budget` is an explicit monotone ledger. Every active limit, including work and replay work, is the componentwise minimum of the requested/default allowance and the permanent store ceiling; a request cannot raise that ceiling. Admission discards failed staged state. Conservative estimates may refuse before the nominal vertex or bit cap is reached. Allocator failure is returned where the underlying API offers fallible reservation; environmental allocator abort behavior has the limitation stated in `docs/design/cas-design.md`.

## Testing · `sec:cas:testing`

Place each test in the outermost layer that can express its assertions. A unit test stays inline under `#[cfg(test)] mod tests` only when it needs a value private to that module. It builds its own setup and never imports the harness. A crate test needs crate-internal access and lives in `src/tests/`, with one file per concern and a `#[cfg(test)] mod tests;` declaration in `src/lib.rs`. An item visible as `pub(crate)` is not module-private. Public tests live under `tests/`.

Public tests use only the crate's public API. `tests/conformance/` checks documented laws, refusals, boundaries, resource limits and determinism. `tests/integration/` exercises complete client computations and proof lifecycles across capabilities, such as constructing a graph, obtaining coverage, searching or differentiating, exporting a witness and replaying it in a fresh store. Classify a test by its principal question or worked flow; setup calls and replay helpers alone do not determine its kind.

Both directories are modules of the single `tests/public.rs` target, with one file per concern. `cargo test -p nrz-cas` includes them without feature flags; `cargo test -p nrz-cas --test public conformance::` and `cargo test -p nrz-cas --test public integration::` select the two public kinds. Both kinds retain the inventory area `integration`, with one existing acute-accent label as each test's final documentation line and a hyphenated function-name slug.

The shared public harness lives in `src/testing/`, included through the private `src/testing/public.rs` entrypoint by source path. Its `test_api` alias refers to the ordinary public library, and it includes no crate-only fixture. Each harness file documents which test binaries compile it. Helpers are absent from ordinary library builds and rustdoc, and the access route adds no feature or dependency. The default, graph, proof and derivation budget profiles remain distinct; test-specific refusal limits stay explicit. Shared setup preserves admission batches, original occurrences, independent oracles and fresh-ledger boundaries. The square-free fixture accepts only a discharged `Proved` result.

The library test binary privately includes `src/testing/mod.rs`, which composes shared public basics and crate-only frontier and frozen-search fixtures. `src/testing/common.rs` is compiled in both binaries. Crate-only fixture files are never reachable from the public entrypoint.

The linter derives each inventory area from the test's location: inline unit tests carry `test:unit`, crate tests under `src/tests/` carry `test:crate`, and public conformance and integration tests carry `test:integration`. Every label is the final documentation line and keeps its acute-accent delimiters.
