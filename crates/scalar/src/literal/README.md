# Scalar literal test support · `guide:scalar:literal-test-support`

**Definition (Evidence scope)** · `def:scalar:literal-test-support`

Literal grammar and enclosure evaluation consume a finite shared work allowance before returning a candidate and its enclosure.

**Rule (Finite literal admission policy)** · `rule:scalar:literal-policy`

The default digit, exponent and work ceilings bound accepted literal descriptions and their evaluation; the per-byte work charge reserves grammar and candidate scans before enclosure operations spend the remaining allowance. These are finite admission choices, not completeness or successful-cost guarantees.
