# nrz-accuracy

Dimension-neutral nonnegative bounds and conservative accuracy policies.

Part of the Naturrhythmuszentrum physics calculation engine.

Version 0.0.1 is a test deploy with no functionality. We are testing our crate development process before committing to a tagged release. The engine is under active development at https://github.com/naturrhythmuszentrum/naturrhythmuszentrum, with 0.1.0 from `main` planned as the first functional release.
